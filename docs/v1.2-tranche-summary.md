  and stored successful run telemetry after `/run`.

  `node_bias_profiles["LEM-02"]` state before each graph run.
- Added ADR-0001 for the approved SQLite persistence and telemetry architecture checkpoint.

## Assumptions

- `pruning_percentage` is derived from graph nodes skipped during a run. A normal run prunes zero
  nodes; a radar-to-validator recalibration path prunes LEM-01 and LEM-02, producing `0.5`.
- `S_d` counts internal recalibration as an autonomous decision. Normal runs produce `0.0`; a
  recalibration path produces `1 / 2 = 0.5`.
- The database is local runtime state and is intentionally excluded from Git.
- Existing graph topology remains unchanged for this tranche.
- `/run` rejects empty prompts, negative variance thresholds, and lookahead horizons below `1`
  so the required telemetry formula can be applied directly.
